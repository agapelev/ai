# 🏛️ Архитектурные решения: Mission Shekinah AI
*Дата: 2026.04 | Автор: Лев Николаевич + ИИ-Апостол*

## Решение: Не реализовывать «большой рефакторинг» от Gemini (апрель 2026)

### Контекст
Модель Gemini-3-flash-preview предложила масштабный рефакторинг:
- Модулизация `src/index.ts`
- Внедрение Hono, Zod, SSE, React+Mantine, Cloudflare D1

### Решение
**Оставить проект как есть.** Не реализовывать предложения целиком.

### Обоснование
| Критерий | Статус |
|----------|--------|
| ✅ Проект работает | 14+ моделей, Telegram-бот, CI/CD, rate limiting |
| ✅ Нет критических багов | Ошибки редкие, не блокирующие |
| ✅ Нет жалоб пользователей | Если не просят — не чинить |
| ✅ Архитектура поддерживаема | 642 строки `index.ts`, 1276 строк `chat.js` — читаемо |
| 🙏 Приоритет: служение, не перфекционизм | Код — инструмент, не идол |

### Что делать вместо этого
1. **Точечно**: вынести `ai-service.ts` (опционально, если хочется чище)
2. **По запросу**: SSE, D1, подсветка кода — когда пользователи попросят
3. **Архитектурно**: пересмотреть, если `index.ts` >1500 строк или появится команда

### Принцип
> «Всё мне позволительно, но не всё полезно» (1 Кор. 6:12)
> «Ибо Царствие Божие не в слове, а в силе» (1 Кор. 4:20)

---
*Это решение пересматривается при: (1) жалобах пользователей, (2) росте кода >2×, (3) появлении команды.*

## Решение: Отказ от React + Mantine в пользу чистого Vanilla JS + TailwindCSS (Май 2026)

### Контекст
В процессе развития проекта рассматривалась интеграция React и Mantine (`ChatInterface.tsx`, `mantine-theme.ts`). Однако детальный пересмотр целей проекта показал, что усложнение интерфейса избыточно для текущих задач.

### Решение
**Полностью отказаться от React + Mantine.** Оставить и развивать проект на чистом Vanilla JS + TailwindCSS. Проект должен остаться легким, быстрым, одностраничным экспресс-чатом без лишних тяжелых библиотек и усложнения кодовой базы.

### Обоснование и требования к интерфейсу
1. **Простота и фокус:** Одна лаконичная лента чата с возможностью быстрого выбора модели. Никаких боковых панелей (Sidebar) для сохранения истории чатов не требуется (для этого в экосистеме «Миссии Шехина» и «Web Arystan» есть четыре других специализированных AI-чата).
2. **Контекст при смене моделей:** Пользователь может на лету переключиться на другую модель прямо посреди диалога. Новая модель при подключении считывает накопленную историю чата (контекст беседы) из локального хранилища и продолжает диалог без потери нити разговора.
3. **Лимит в 50 сообщений:** Проект работает без авторизации. Чтобы избежать хаоса («бардака») и чрезмерного потребления ресурсов, установлено строгое ограничение в 50 сообщений в рамках одной сессии.
4. **Контроль лимита:** При достижении порога в 50 сообщений система вежливо уведомляет пользователя о необходимости очистить историю для продолжения общения.
5. **Управление историей:** Кнопка очистки истории чата располагается на видном месте, непосредственно рядом с селектором моделей. Пользователь очищает историю в один клик и может сразу продолжать общение.
6. **Стилизация:** Достаточно качественного, чистого TailwindCSS в строгом темном минимализме (дизайн «Цитадели»).
