## 🏛️ Ключевые Архитектурные Решения проекта (Утверждено 28.05.2026)

> [!IMPORTANT]
> **Полный отказ от React + Mantine.** Проект разрабатывается строго на чистом **Vanilla JS + TailwindCSS**. Никаких тяжелых фреймворков на фронтенде во избежание усложнения кодовой базы.

### Требования к интерфейсу и логике чат-бота:
1. **Одностраничный дизайн:** Одна лаконичная лента чата без боковых панелей (Sidebar) для сохранения истории. Вся функциональность сосредоточена на одном экране.
2. **Динамическое переключение моделей:** Пользователь может сменить модель прямо в процессе диалога. Новая модель при подключении считывает всю историю чата (контекст беседы) из локального хранилища и продолжает диалог без разрыва нити общения.
3. **Строгий лимит в 50 сообщений:** Поскольку проект является анонимным (без авторизации), во избежание хаоса («бардака») и перегрузки установлено строгое ограничение на 50 сообщений.
4. **Уведомление и контроль:** При достижении лимита в 50 сообщений чат вежливо сообщает пользователю о необходимости очистить историю для продолжения общения.
5. **Кнопка очистки истории:** Располагается непосредственно рядом с селектором моделей для быстрого доступа.
6. **Стилистика:** Строгий темный минимализм Цитадели на чистом TailwindCSS. Гармоничные темные оттенки, плавная прокрутка, аккуратные микроанимации.
